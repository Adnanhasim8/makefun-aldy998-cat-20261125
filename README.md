# The One-Line Cat Joke That Lands

Entry for the make.fun competition `u-aldy998-the-one-line-cat-joke-that-lands-a7b18262`.
`main.py` writes one one-line joke about cats (a setup with a hard twist in the
last words, concrete nouns, nothing explained) to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Python 3.13 standard library only; no network at run time.
